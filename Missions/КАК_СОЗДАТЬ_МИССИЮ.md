# Как создать миссию — простая инструкция

> Главное правило: **всё создаётся прямо в инспекторе**, вложенными ресурсами.
> Когда видишь поле (Choices, Outcome, Battle…) — кликни по нему → **New [Тип]** →
> заполни поля. Ничего не нужно писать кодом.

---

## Шаг 0. Создай файл сцены миссии

1. Внизу слева панель **FileSystem** → правый клик по `Missions/` →
   **Create New → Resource…**
2. В поиске введи `MissionSceneResource` → выбери → **Create**.
3. Сохрани как `my_scene.tres`.

## Шаг 1. Заполни текст сцены

В **Inspector** (справа):
- **Scene Title** — короткое название (заголовок).
- **Body Text** — основной текст (описание ситуации). Поддерживает BBCode: `[b]жирный[/b]`.
- **Image** — перетащи картинку (можно пусто).

## Шаг 2. Добавь варианты ответа

1. В поле **Choices** → кнопка **Add Element** (появится пустой элемент `[ ]`).
2. Кликни по пустому элементу → выпадающее меню → **New MissionChoice**.
3. Откроются поля выбора:
   - **Choice Text** — текст кнопки ответа (напр. «Напасть»).

Повтори **Add Element** для каждого варианта.

---

## Шаг 3. Что произойдёт при выборе (Outcome)

У каждого MissionChoice есть поля:
- **Outcome** — что случится (если без проверки).
- **Stat Check** — если нужна проверка характеристики.
- **Success Outcome / Failure Outcome** — итогы при успехе/провале проверки.
- **Required God** — выбор доступен только если этот бог есть у игрока.

### Простой выбор (без проверки)
1. Кликни **Outcome** → **New MissionOutcome**.
2. Заполни:
   - **Result Text** — текст итога (напр. «Вы победили!»).
   - **Next Scene** — перетащи ДРУГУЮ сцену (ветвление) или оставь пусто (конец).
   - **Battle** — кликни → **New BattleConfig** (см. шаг 4).
   - **Rewards** → Add Element → **New Reward** (см. шаг 5).

### Выбор с проверкой характеристики
1. Кликни **Stat Check** → **New StatCheck**.
2. Заполни: **Stat** (напр. Attack), **Difficulty** (порог, напр. 50), **Coefficient** (напр. 1.0).
3. Кликни **Success Outcome** → **New MissionOutcome** → заполни (что при успехе).
4. Кликни **Failure Outcome** → **New MissionOutcome** → заполни (что при провале).

> Бросок = случайное 0..100 + средний стат команды × коэффициент.
> Успех если результат ≥ Difficulty.

### Выбор только для конкретного бога
- В **Required God** перетащи файл бога (напр. `Gods/Loki/Loki.tres`).
- Если бога нет у игрока — кнопка заблокирована, подпись «(нужен Локи)».

---

## Шаг 4. Бой (BattleConfig)

В поле **Battle** (внутри Outcome) → **New BattleConfig**:
- **Formation** — перетащи файл построения (`FormationResource`, 4 позиции врагов).
  *Построение создаётся отдельно: Create New → FormationResource → расставь врагов.*
- **Enemy Modifiers** → Add Element → **New UnitModifier** — модификатор врага:
  - **Target Position** (0=все, 1–4 = позиция), **Hp Percent** (напр. 80), **Passive Charges** (напр. 7).
  - **Buffs** → Add Element → **New BuffEntry**: **Stat** (урон/удача/…), **Value** (−20), **Duration** (−1=весь бой, 1=1 ход).
- **Location Id** — локация боя (`"helheim"`, `"hell"`, `""` = локация миссии).

## Шаг 5. Награды (Reward)

В поле **Rewards** (внутри Outcome) → Add Element → **New Reward**:
- **Kind** — Item / Essence / God.
- **Resource** — перетащи файл (ItemResource / EssenceResource / CharacterResource).
- **Amount** — сколько (для эссенций).

---

## Шаг 6. Добавь сцену в миссию

1. Создай/открой файл миссии (`MissionResource`, напр. `main_mission.tres`).
2. В поле **Scenes** → **Add Element** → перетащи свой `my_scene.tres`.
3. **Mission Name** — название миссии.
4. **Location** — локация для всех боёв миссии (опц.).

## Шаг 7. Открой миссию в игре

В `mission_select.tscn` → выдели корень **MissionSelect** → в Inspector впиши путь
к миссии в **Mission Path** (напр. `res://Missions/main_mission.tres`).

---

## Минимальный рабочий пример (одна сцена, 1 выбор → бой)

```
MissionSceneResource (my_scene.tres)
├─ scene_title = "Засада"
├─ body_text  = "На вас нападают!"
└─ choices = [
	MissionChoice
	├─ choice_text = "Сразиться"
	└─ outcome = MissionOutcome
	   ├─ result_text = "Вы одолели врагов!"
	   └─ battle = BattleConfig
		  └─ formation = <перетащи построение с врагами>
  ]
```

Этого достаточно, чтобы бой запустился. Добавь ещё choices, stat_check, rewards,
required_god — по мере необходимости, следуя шагам выше.

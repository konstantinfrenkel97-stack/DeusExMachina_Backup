# Гайд: создание сцены миссии (всё в одном файле)

Сцена миссии — это **один файл `.tres`**, в который ты сразу вставляешь:
картинку, текст и все варианты ответа. Отдельные файлы для ответов **не нужны**.

> Готовый пример одним файлом: [`scene_inline_example.tres`](scene_inline_example.tres:1).

---

## Способ 1 (простой): в редакторе Godot через инспектор

### 1. Создай файл сцены миссии
В панели **FileSystem** (внизу слева) правый клик по папке `Missions/` →
**Create New** → **Resource...** → введи `MissionSceneResource` → выбери → **Create**.
Сохрани, например `scene_meet.tres`.

### 2. Заполни основные поля (справа в Inspector)
- **Scene Title** — короткое название (текст квадратной кнопки в списке миссии).
- **Image** — перетащи сюда свою картинку (PNG). Можно оставить пустым.
- **Body Text** — основной текст сцены. Поддерживает BBCode: `[b]жирный[/b]`, `[i]курсив[/i]`.

### 3. Добавь ответы прямо в этот же файл
- Нажми на **Choices** → кнопка **Add Element** (появится пустой элемент).
- Кликни по пустому элементу → выбери **New MissionChoice** (создать встроенный).
- Справа откроются поля ответа:
  - **Choice Text** — текст кнопки ответа.
  - **Effects** — что произойдёт (пока текст-заглушка).
  - **Launch Battle** — галочка для запуска боя.
  - **Battle Setup Path** — путь к файлу боя (если включил бой).
  - **Next Scene** — перетащи другую сцену, чтобы после ответа открылась она.
- Повтори **Add Element** для каждого ответа.

Все ответы сохранятся **внутри** файла `scene_meet.tres` — одного файла хватает.

## Способ 2 (для тех, кто правит `.tres` напрямую)

Можно написать весь файл руками. Пример — один файл с двумя встроенными ответами
(картинка `image` добавляется строкой `image = ExtResource(...)` при желании):

```
[gd_resource type="Resource" script_class="MissionSceneResource" load_steps=3 format=3]

[ext_resource type="Script" path="res://Missions/mission_scene_resource.gd" id="1_msr"]
[ext_resource type="Script" path="res://Missions/mission_choice.gd" id="2_mc"]

[sub_resource type="Resource" id="Choice_1" script=ExtResource("2_mc")]
choice_text = "Напасть"
effects = "Шаблон: начинается бой."
launch_battle = true
battle_setup_path = "res://battle_setup.tscn"

[sub_resource type="Resource" id="Choice_2" script=ExtResource("2_mc")]
choice_text = "Поговорить"
effects = "Шаблон: +10 доверия."
launch_battle = false

[resource]
script = ExtResource("1_msr")
scene_title = "Первая встреча"
body_text = "На тропе стоит незнакомец. Что будешь делать?"
choices = [SubResource("Choice_1"), SubResource("Choice_2")]
```

Чтобы добавить картинку — добавь ещё одну строку:
```
[ext_resource type="Texture2D" path="res://Missions/images/meet.png" id="3_img"]
```
и в `[resource]`:
```
image = ExtResource("3_img")
```

## Как добавить сцену в список кнопок миссии

Открой файл миссии (например [`main_mission.tres`](main_mission.tres:1)) → в поле
**Scenes** → **Add Element** → перетащи туда свой `scene_meet.tres`.
Каждая сцена в этом списке = одна квадратная кнопка на экране «Миссия».

> Чтобы экран открыл именно эту миссию — в `mission_select.tscn` выдели корень
> **MissionSelect** и впиши путь к миссии в поле **Mission Path**.

# Локация миссии

В файле миссии (`MissionResource`) есть поле **Location** — выпадающий список со всеми
локациями игры (Хельхейм, Ад, Пустыня, Арена и т.д.).

Если выбрать локацию (не NONE) — **любая битва**, запущенная из этой миссии, будет
проводиться на этой локации со всеми её правилами и визуалом (фон, туман, эффекты).

При запуске боя из миссии:
- Кнопка выбора локации в `battle_setup` будет **заблокирована** (🔒).
- Локация применится автоматически — игрок не сможет её сменить.
- Кнопки врагов (если есть построение) тоже будут заблокированы.

### В редакторе Godot

1. Открой файл миссии (`*.tres` с типом `MissionResource`).
2. В **Inspector** найди поле **Location**.
3. Выбери нужную локацию из выпадающего списка (NONE = игрок выбирает сам).

### Напрямую в `.tres`

Поле `location` — это число (enum). Номера локаций:

| № | Локация | № | Локация |
|---|---------|---|---------|
| 0 | Хельхейм | 9 | Глубина |
| 1 | Ад | 10 | Остров |
| 2 | Тоннели | 11 | Корабли |
| 3 | Облака | 12 | Джунгли |
| 4 | Звёзды | 13 | Сад |
| 5 | Горы | 14 | Топь |
| 6 | Арена | 15 | Дом |
| 7 | Замок | 16 | Книга |
| 8 | Пустыня | 17 | NONE (нет локации) |

Пример — миссия на Пустыне (номер 8):
```
[resource]
script = ExtResource("1_mr")
mission_name = "Миссия в пустыне"
location = 8
scenes = [ExtResource("3_scene")]
```

## Шпаргалка: что куда

| Что | Файл | Поле |
|-----|------|------|
| Заголовок/текст кнопки | MissionSceneResource | **Scene Title** |
| Картинка | MissionSceneResource | **Image** |
| Основной текст | MissionSceneResource | **Body Text** |
| Ответы (внутри файла) | MissionSceneResource | **Choices** → New MissionChoice |
| Текст кнопки ответа | MissionChoice | **Choice Text** |
| Бой против конкретных врагов | MissionChoice | **Formation** → FormationResource |
| Запуск боя (без построения) | MissionChoice | **Launch Battle** + **Battle Setup Path** |
| Переход к другой сцене | MissionChoice | **Next Scene** |
| Кнопки экрана миссии | MissionResource | **Scenes** |
| Состав врагов на 4 позициях | FormationResource | **Pos 1–4** (CharacterResource) |

# Формат «Построение» (состав врагов для боя)

Построение — это **отдельный файл `.tres`**, в котором заданы 4 позиции врагов
(как ряд врагов в битве). Если подключить построение к варианту ответа —
при выборе этого ответа **откроется экран выбора героев**, где враги уже
расставлены и **заблокированы** (их нельзя поменять). Игрок выбирает только
своих героев, затем нажимает «В бой».

> Готовый пример: [`formation_desert_ambush.tres`](formation_desert_ambush.tres:1) +
> сцена с подключённым построением: [`scene_with_formation.tres`](scene_with_formation.tres:1).

---

## Создание файла Построения

### Способ 1 (простой): в редакторе Godot

1. В **FileSystem** правый клик по `Missions/` → **Create New** → **Resource...**
   → введи `FormationResource` → **Create**. Сохрани, например `formation_boss.tres`.
2. В **Inspector** заполни:
   - **Formation Name** — название (для удобства, не показывается игроку).
   - **Pos 1, Pos 2, Pos 3, Pos 4** — четыре слота для врагов.
	 В каждый слот перетащи файл врага (`.tres` из папки `Enemies/`).
	 Можно также кликнуть по пустому слоту и выбрать **Quick Open** или **Load**
	 чтобы найти файл. Лишние позиции оставь пустыми.

### Способ 2: напрямую в `.tres`

```
[gd_resource type="Resource" script_class="FormationResource" load_steps=4 format=3]

[ext_resource type="Script" path="res://Missions/formation_resource.gd" id="1_fr"]
[ext_resource type="Resource" path="res://Enemies/.../Draugr_raider.tres" id="2_e1"]
[ext_resource type="Resource" path="res://Enemies/.../Mummy.tres" id="3_e2"]

[resource]
script = ExtResource("1_fr")
formation_name = "Засада в пустыне"
pos1 = ExtResource("2_e1")
pos2 = ExtResource("3_e2")
pos3 = null
pos4 = null
```

## Подключение построения к варианту ответа

### В редакторе Godot

1. Открой свою сцену миссии (`scene_*.tres`).
2. В **Choices** → выбери нужный **MissionChoice**.
3. В поле **Formation** перетащи файл построения (`formation_*.tres`).
4. При выборе этого ответа начнётся бой против врагов из построения.

### Напрямую в `.tres` (сцена со встроенным ответом + внешним построением)

```
[ext_resource type="Resource" path="res://Missions/formation_desert_ambush.tres" id="3_form"]

[sub_resource type="Resource" id="Choice_1" script=ExtResource("2_mc")]
choice_text = "Напасть на засаду"
formation = ExtResource("3_form")
```

> **Важно:** если у ответа задано поле **Formation**, поля **Launch Battle**
> и **Battle Setup Path** игнорируются — построение имеет приоритет.

---

## Правила больших юнитов в построении

- Обычный юнит занимает **1 позицию**.
- **Большой юнит** (`is_large`) занимает позицию `i` **и блокирует** соседнюю `i+1`
  — её нужно оставить пустой (null).
- Например: большой юнит на позиции 2 → позиция 3 должна быть пустой.
  Позиция 4 может быть занята.
